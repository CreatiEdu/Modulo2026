#Requerimentos Del Sistema

## Requerimentos Funcionales (RF)

RF1 - Registro y Login de Usuarios: El sistema debe permitir el registro de usuarios (clientes y administradores) mediante correo electrónico y contraseña, gestionando niveles de acceso diferenciados.

RF2 - Visualización y Filtrado de Propiedades: El sistema mostrará un catálogo de inmuebles con fotos, precios y descripción. Permitirá filtrar por ubicación, rango de precios, tipo de propiedad (casa, departamento, terreno) y cantidad de ambientes.

RF3 - Gestión de Publicaciones (CRUD): Los administradores podrán crear, editar, listar y eliminar las propiedades publicadas en el catálogo.

RF4 - Formulario de Contacto e Interés: El sistema permitirá a los usuarios interesados enviar una solicitud de información o coordinar una visita directamente desde el detalle de la propiedad.

RF5 - Favoritos: El usuario registrado podrá marcar propiedades como "favoritas" para acceder rápidamente a ellas desde su perfil personal.

## Requerimentos No Funcionales (RNF)

RNF1: El sistema deberá ser accesible desde distintos dispositivos (responsive: PC, tablet y celular).

RNF2: El sistema deberá tener tiempos de respuesta rápidos (carga de páginas menor a 3 segundos).

RNF3: El sistema deberá garantizar la seguridad de los datos, evitando accesos no autorizados al panel de administración.
